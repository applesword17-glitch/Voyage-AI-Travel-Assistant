# AI Travel Assistant

Python + Streamlit + Google Gemini/Vertex AI prototype.

Features: conversational planning, personalized itineraries, iterative refinement, budget/season/interests context, travel mood, practical advice, local rules/customs, Google Search grounding, and destination imagery.

Setup: install Python, create a virtual environment, run `pip install -r requirements.txt`, copy `.env.example` to `.env`, configure Google credentials, then run `streamlit run app.py`.
